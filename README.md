# CQMA TOOLS 

This R package contains the tools for processing the data collected by the
Greenhouse Gas Laboratory (in Portuguese: *Laboratório de Gases de Efeito
Estufa LaGEE*) at the National Institute for Space Research in Brazil (INPE).

These tools have been used for processing the data collected by LaGEE and used
to support the findings reported in the publications listed below.

In particular, this package contains scripts useful for estimating vertical
profiles of greenhouse gas concentration [[1]](#1) and regions of influence
of single particle trajectory models [[2]](#2). These data products support the
findings reported in [[3]](#3), [[4]](#4), [[5]](#5), and [[6]](#6).

For more information, visit LaGEE at
[www.ccst.inpe.br/lagee](https://www.ccst.inpe.br/lagee).
