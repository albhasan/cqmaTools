# CQMA TOOLS 

This is an R package containing the tools for processing the data collected by
the Greenhouse Gas Laboratory (in Portuguese: *Laboratório de Gases de Efeito
Estufa LAGEE*) at the National Institute for Space Research in Brasil (INPE).



For more information, visit LAGEE at [www.ccst.inpe.br/lagee]
(https://www.ccst.inpe.br/lagee).
